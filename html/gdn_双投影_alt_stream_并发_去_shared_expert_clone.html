01

优化背景

做这件事的场景和动机

Qwen3.5 v0.5.9 decode 优化。GDN 层入口两个投影的串行发射在小 batch decode 下是纯 launch/等待开销；用 alt-stream 让 GPU 同时跑两个 kernel 是 CUDA graph 场景常见的并发填充手段。clone 去除则是延续此前 gating 融合与 verify 去 clone 系列的"删冗余拷贝"。env 开关化让不稳定的 qk-norm 双流可按需关闭，不拖累默认路径。

02

好处与收益

  • GDN 双投影并发执行，窄 GEMM 的等待被大 GEMM 掩盖；shared expert 每层省一次 hidden_states clone。
03

Trade-off

正确性债、分叉和退化
  • alt-stream 仅在 CUDA graph capture 模式生效；非 capture 路径回退串行。双流引入跨流同步（wait_stream），短 kernel 上同步开销会吃掉并发收益——这也是把 qk-norm 双流降级为 env 开关（默认关）的原因。
  • 并发执行增加瞬时寄存器/SM 资源竞争，极端形状下互相拖慢。
  • 去 clone 后 shared expert 与 router 共享输入张量，依赖两者确实只读的约定。
